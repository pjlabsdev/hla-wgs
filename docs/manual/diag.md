# Diagnostic package

    hla-wgs diag OUTPREFIX

Writes `OUTPREFIX.diag.tar` with the run log (`diag.log.jsonl`, `diag.log.txt`) and the version of
the program. It holds no results, no reads and no folder names; attach it to a bug report. The log
format is in [run log](log.md), the procedure in [procedures](procedures.md#report-a-bug).
