# Result page again

    hla-wgs html PREFIX.json

Writes `PREFIX.html` again from `PREFIX.json`, for example after an update of the program that
changed the page. Nothing is typed again. The page is described in [output](../output.md); its
language follows `HLA_WGS_LANG` or `LANG` and can be switched on the page.

Errors: HW-E021 (not a result file), HW-E020 (cannot write), see [error codes](errors.md).
