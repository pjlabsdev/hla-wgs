HLA-Typisierung im BrowserHLA typing in your browser

hla-wgs läuft hier vollständig auf Ihrem Computer. Ihre BAM-, CRAM- oder FASTQ-Dateien werden nicht hochgeladen; die Seite liest nur die HLA-Region auf Chromosom 6 über den Index. Ergebnis und Dateien sind dieselben wie beim Programm für macOS, Linux und Windows. hla-wgs runs entirely on your computer here. Your BAM, CRAM or FASTQ files are not uploaded; the page reads only the HLA region on chromosome 6 through the index. Result and files are the same as from the program for macOS, Linux and Windows.

1Referenz IPD-IMGT/HLAReference IPD-IMGT/HLA

Beim ersten Mal lädt die Seite die Datenbank hla.dat (Release 3.66, 45 MB) direkt von IPD-IMGT/HLA auf GitHub und baut daraus die Referenz, einmalig etwa 5 bis 10 Minuten. Danach bleibt sie im Browser gespeichert. Wer hla-wgs schon installiert hat, kann stattdessen den Ordner ref/hladb neben der Startdatei wählen. The first time, the page downloads the database hla.dat (release 3.66, 45 MB) directly from IPD-IMGT/HLA on GitHub and builds the reference from it, once, in about 5 to 10 minutes. After that it stays stored in the browser. If hla-wgs is already installed, choose the folder ref/hladb next to the start file instead.
